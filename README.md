# Manhunt

队伍创建
/hunters /runners 命令，游戏进行中不可再切换队伍；同队重复执行会补发/移除追踪指南针
指南针指向最近的runner，当前维度没有runner就指向最近的存储的runner最后位置
游戏开始逻辑：开始前冻结时间，玩家状态重置，没有人无队伍且至少有1runner 1hunter时自动开始游戏
游戏结束逻辑：所有 runner 死亡，或掉线超过 60 秒视为淘汰后，进入 30 秒倒计时，归零后不关闭服务器，直接删除并重新生成所有维度（主世界 / 下界 / 末地 / 自定义维度），玩家自动进入新主世界并重新选择队伍
重置时离线的玩家会在下次上线时补做个人状态重置
