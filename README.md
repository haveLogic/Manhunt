# Manhunt

Minecraft Manhunt 小游戏模组：猎人追捕跑者，跑者全部淘汰后自动重建世界并开始下一局。

## 玩法

- 玩家使用 `/hunters` 或 `/runners` 选择队伍；除管理员（OP）外所有玩家都选好队，且至少各有 1 名猎人和跑者时，游戏自动开始。
- 管理员可以不选队，不影响开局；这类管理员不参与本局，开局时会收到提示。
- 开局前时间冻结；开局后时间恢复流动。
- 猎人持有追踪指南针，指向当前维度中最近的跑者。
- 当前维度没有跑者时，指南针指向跑者在该维度最后被记录的位置。
- 游戏开始后不能更换队伍；无队伍的玩家可以中途加入猎人队伍。

## 淘汰与结算

- 跑者死亡即淘汰。
- 跑者掉线超过 3 分钟视为淘汰；期间重新上线则继续游戏。
- 超时淘汰不可撤销：一旦判定，倒计时期间重新上线也不会中止重置。
- 所有跑者淘汰后进入 30 秒倒计时，归零后服务器不会关闭，而是：
  - 删除并重新生成所有维度（主世界、下界、末地、自定义维度）；
  - 使用新种子生成新世界，时间归零；
  - 重置玩家个人数据（背包、末影箱、配方、统计、成就、经验等）；
  - 将玩家传送到新主世界出生点，需重新选择队伍。
- 重置时离线的玩家，会在下次上线时补做个人数据重置。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/hunters` | 加入猎人队伍并发放追踪指南针；重复执行会补发缺失的指南针；游戏进行中也可中途加入（仅限当前无队伍的玩家） |
| `/runners` | 加入跑者队伍；重复执行或从猎人换队时移除追踪指南针；游戏进行中不可加入 |

## 环境要求

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | ≥ 0.19.5 |
| Fabric API | 0.165.0+26.3 |
| Java | ≥ 25 |

## 构建

```bash
./gradlew build
```

构建产物位于 `build/libs/manhunt-1.0.0.jar`。

## 开发

```bash
./gradlew runClient   # 启动开发客户端
./gradlew runServer   # 启动开发服务器
```
